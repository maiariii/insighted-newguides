InsightED eSF7 · School Head Portal

User Input Guide for Completing eSF7 on InsightED

A section-by-section operating guide for signing in, encoding school personnel data, building classes and workloads, validating records, and generating official reports.

Operating rule: Use the left sidebar in the app as your sequence. Start with school identity, then personnel, then classes, then workload, then validation. Do not submit until the Validation Center shows no critical errors.
A

Sign in and understand the workspace

Step 1: Open the portal

  1. Open the InsightED eSF7 web app in a browser.
  2. Wait for the login screen to finish loading.
  3. If the app remembers a previous school account, confirm that the remembered school is the one you need to update.

Step 2: Sign in with passcode or password

  1. Enter the 6-digit School ID in School Identifier.
  2. Use the 6-digit passcode boxes if you are in passcode mode.
  3. Select Use Password Instead only when your account was issued a password login.
  4. Click SIGN IN →.
Data stored after login: the app keeps the token, remembered user, and school ID in local browser storage so the session can restore quickly.

Step 3: Use the sidebar sequence

The app sections are grouped as ESF7, Teaching Overload, Others, then the bottom Validation Center.

B

Dashboard and automatic eSF7 file harvester

Step 1: Review dashboard counts

The Dashboard summarizes total personnel, teaching personnel, related-teaching personnel, non-teaching personnel, workload distribution, and compliance checks.

Step 2: Upload an existing eSF7 file

  1. Click Upload eSF7 File (.xlsb).
  2. Drag an official DepEd eSF7 spreadsheet into the modal or click the upload zone.
  3. Accepted formats are .xlsb and .xlsx.
  4. Wait for the browser harvester to parse personnel and workload slots.
Important: harvested data loads into a local draft first. Review names, positions, workloads, and timetable times before final submission.

Step 3: Select records to import

  1. In the extracted personnel table, keep only the records you want to import checked.
  2. Use Select All or Deselect All if needed.
  3. Click Auto-Populate Personnel (Local Draft).

Step 4: Resolve harvested data warnings

The app may flag harvested timetables for start/end time verification. Visit the Workload section and inspect rows before submitting.

C

School Profile

Step 1: Check official school identity

The School Profile page is primarily read-only and should match the Unit 1 Schools Identity Registry.

School IDOfficial DepEd school identifier.
School NameRegistered school name.
Region / Division / DistrictAdministrative location fields.
School YearActive school year for encoded records.
Number of ShiftsUsed for validation and workload context.

Step 2: Confirm curricular offerings

Check which program cards are active: Elementary, Junior High School, and Senior High School. These offerings affect available grade levels and workload subjects.

Step 3: Do not force-edit registry fields

If school identity looks wrong, treat it as a registry issue. Do not submit final eSF7 data until the correct school profile is loaded.
D

Personnel Roster

Step 1: Filter and search the roster

  1. Use the category tabs: All, Teaching, Teaching-related, and Non-teaching.
  2. Use the search box for names, DepEd email, category, or position.
  3. Click column headers to sort by designation, names, email, category, position, or school-head status.

Step 2: Add personnel manually

  1. Click + Add personnel.
  2. Enter designation, first name, middle name, last name, extension name, DepEd email local part, position category, and position.
  3. Click Add Personnel.
  4. The app opens Personnel Profiling so you can complete the rest of the record.

Step 3: Assign the school head

Use the School Head toggle on the roster. The app prevents more than one Principal, OIC, or TIC from being assigned at the same time.

Step 4: Open related work areas

Use Profile to edit the complete personnel record. Use Work to jump directly to workload encoding for that person. Use ✕ only after confirming the record should be deleted.

E

Personnel Profiling

Step 1: Select the correct personnel record

Use the left personnel list, search, category filter, and position filter to select the correct staff member before editing fields.

Step 2: Complete identity and demographics

NamesFirst, middle, last, extension, salutation.
Sex at birth / civil statusRequired for validation.
Religion / ethnic groupUse the dropdown values when possible.
BirthdateUse the date picker; age validation runs automatically.
TIN / No TINTIN must use the 123-456-789 format unless No TIN applies.
DepEd emailMust use the @deped.gov.ph domain.

Step 3: Complete employment fields

  1. Select position and category.
  2. Choose fund source, nature of appointment, hiring arrangement, and deployment status.
  3. For clustered, reassigned, borrowed, or detailed deployment, select the assigned receiving school.
  4. Enter service and movement dates: first service, last promotion, last lateral movement, and first day in current station.

Step 4: Complete qualifications

Enter college degree, major, minor, post-graduate degree, discipline, eligibility, and PRC specialization when required. LET or PBET eligibility requires PRC specialization.

Step 5: Add trainings and learning areas

  1. Add at least one professional development / training record.
  2. For each training, enter title, start date, end date, number of days, hours per day, and total hours.
  3. Use the Learning Area Matrix to mark subjects taught by school year.

Step 6: Save or validate

Use Save Changes to persist edits. Use Save & Validate when the profile is complete and ready for final checks.

F

Designations

Step 1: Search the designation list

Use the search box to find roles such as Department Head, ICT Coordinator, Guidance Coordinator, BAC Chair / Member, SDRRM Coordinator, Reading Coordinator, or Property Custodian.

Step 2: Assign personnel

  1. Open the dropdown under the designation card.
  2. Select an active personnel record.
  3. Confirm the assigned badge appears on the card.

Step 3: Remove or replace assignments

Use Remove to unassign the current personnel, or select another person in the dropdown to replace the assignment.

G

Organized Classes

Step 1: Add a class section

  1. Click the section add button in Organized Classes.
  2. Select the grade level allowed by the school's curricular offerings.
  3. Enter the section name in uppercase.
  4. Enter number of learners.
  5. Select a section adviser.
  6. Click Add Section.

Step 2: Create multigrade sections carefully

  1. Check This is a multigrade section.
  2. Select 2 to 6 grade levels.
  3. Avoid grade levels already assigned to another multigrade combination.

Step 3: Configure subjects taught

  1. Choose the grade band: Elementary, Junior High School, or Senior High School.
  2. Filter by grade level or SHS category.
  3. Enable or disable subjects for the school.
  4. Add custom subjects only when they are valid for the school context.
Restricted items such as Advisory, HGP, and Mother Tongue are controlled by the system and should not be added as custom subjects.
H

Workload

Step 1: Choose the teacher

Select a teacher from the Workload screen before adding or editing workload rows. The app calculates weekly load, daily average load, and overload indicators from the encoded schedule.

Step 2: Add teaching workload rows

  1. Click + Add Workload Row.
  2. Select the class section first.
  3. Select the subject from the grade-appropriate list.
  4. Tick the meeting days: M, T, W, TH, F.
  5. Enter start time and end time.

Step 3: Respect schedule limits

RuleExpected behavior
Elementary / JHS subject periodSingle period should not exceed 60 minutes.
SHS subject blockMay use longer blocks, capped by the app at 6 hours.
AdvisoryLocked at 60 minutes per day, Monday to Friday.
HGPTracked separately and does not add extra teaching load minutes.
Overlapping schedulesThe app alerts when two rows conflict on the same day and time.

Step 4: Encode teaching-related and administrative rows

Use the workload panels for teaching-related duties, administrative tasks, coaching, mentoring, and other non-classroom assignments where applicable.

Step 5: Use work immersion calendar for SHS

For SHS work immersion supervision, select monthly dates and save start/end times. These schedules integrate into overload pay computation.

I

Room QR Portal

Step 1: Generate a room QR poster

  1. Enter the assigned room name.
  2. Confirm the generated room link and QR code.
  3. Use Copy Link or print/place the QR poster for teachers.

Step 2: Distribute teacher passcodes

Use the Teacher Passcodes table to copy or regenerate each teacher's 6-character profiling code. Teachers need the code to open their own profiling form.

Step 3: Scan teacher submissions

  1. Use Scan with Webcam to scan a QR code directly.
  2. Or upload a QR screenshot image.
  3. Review detected differences in the modal.
  4. Click Approve & Commit Changes only after checking the submitted values.
The QR exchange is browser-local: the teacher profile data is reviewed before it is committed back into the central app state.
J

Requests

Step 1: Review incoming requests

Incoming requests include clustered personnel sharing and school integration / merger requests. Use Approve or Reject.

Step 2: Review outgoing requests

The Outgoing tab shows requests your school has sent and their current status: pending, approved, or rejected.

Step 3: Initiate integration or merger

  1. Open Initiate Integration/Merger.
  2. Select the target host school within the district.
  3. Click Send Merger Request.
Approval may permanently transfer personnel into the host school. Confirm the target school before sending.
K

Teaching Overload Center

Step 1: Log tardiness

  1. Open Step 1 · Tardiness Log.
  2. Select the teacher and month.
  3. Click workdays to toggle tardiness / late entries.
  4. Remove incorrect entries from the log history.

Step 2: Log absences and leave

  1. Open Step 2 · Absences & Leave.
  2. Select the leave type, teacher, and month.
  3. Click start and end dates to set the leave range.
  4. Avoid duplicate entries for the same teacher and date.

Step 3: Transfer workloads

  1. Open Step 3 · Workload Transfers.
  2. Select the absent teacher and date range.
  3. Assign substitute teachers for the affected workload slots.
  4. Resolve conflict alerts before saving the transfer.

Step 4: Record work immersion

Open Step 4 · Work Immersion, choose a teacher and month, then enter daily start/end times for immersion supervision.

Step 5: Compute and print overload pay

  1. Open Step 5 · Teaching Overload.
  2. Select month and term.
  3. Search teachers if needed.
  4. Add at least one reason for each teacher with overload.
  5. Click Generate Report (PDF).
Eligibility filter: the app excludes school heads, non-teaching personnel, teaching-related personnel, principals, TIC/OIC, administrative roles, and similar non-eligible roles from overload pay computation.
L

Allowances & Incentives

Step 1: Review active personnel

The table lists non-draft, non-shared active personnel in a frozen left column.

Step 2: Tick applicable allowances

ColumnMeaning

Step 3: Confirm saved status

Each checkbox change sends an update. Wait for the success toast before moving quickly through many personnel.

The Validation Center blocks final submission when no allowances or incentives are checked for any active personnel.
M

Validation Center and official reports

Step 1: Review validation KPIs

The Validation Center summarizes errors, warnings, duplicate flags, and ready records. Click issue rows to jump to the profile or module that needs fixing.

Step 2: Fix all critical errors

Issue areaTypical fix
School HeadAssign only one Principal, OIC, or TIC.
IdentityComplete names, TIN/No TIN, birthdate, and duplicate checks.
EmploymentComplete position, fund source, appointment, hiring arrangement, deployment status, and assigned schools.
QualificationsComplete college degree, eligibility, and PRC specialization when LET/PBET applies.
WorkloadAdd teaching workload rows and fix invalid durations or conflicts.
AllowancesTick at least one allowance or incentive.

Step 3: Preview teacher class programs

Open the Teacher Class Programs (VIEW Sheet Preview) tab to inspect schedules by teacher. Expand teacher rows to confirm subjects, sections, days, times, and weekly minutes.

Step 4: Print or save report PDF

Click Print / Save PDF Report to open the printable report modal. Use browser print settings to save a PDF copy.

Step 5: Certify and submit

  1. Confirm there are no critical errors.
  2. Tick the certification checkbox.
  3. Confirm the school head / principal name.
  4. Add or verify the e-signature by drawing or uploading an image.
  5. Click Submit Certified eSF7 to Queue.
  6. Wait for queue status to complete before closing the page.
After successful submission, the app clears drafts and reloads from the official database state.
Final rule: complete school profile → roster → personnel profile → classes → workload → allowances → validation before submitting certified eSF7 data.
